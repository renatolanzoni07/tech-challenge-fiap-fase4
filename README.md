# Tech Challenge - FIAP Fase 4

## Objetivo

Desenvolver um modelo preditivo para identificação dos níveis de obesidade utilizando técnicas de Machine Learning e disponibilizar a solução em uma aplicação Streamlit.

## Tecnologias Utilizadas

- Python
- Pandas
- Scikit-Learn
- Streamlit
- Plotly
- Joblib

## Etapas do Projeto

1. Carregamento e tratamento dos dados
2. Análise Exploratória dos Dados (EDA)
3. Feature Engineering
4. Treinamento do Modelo
5. Avaliação dos Resultados
6. Desenvolvimento do Dashboard Analítico
7. Deploy da Aplicação em Streamlit

## Principais Insights

- O IMC apresentou forte relação com os níveis de obesidade.
- O histórico familiar demonstrou influência significativa na classificação.
- Menores níveis de atividade física estão associados a maiores níveis de obesidade.
- A base apresentou distribuição equilibrada entre as classes.

## Modelo Utilizado

- Algoritmo: Random Forest
- Accuracy: 98%

## Aplicação

A aplicação possui:

- Home
- Dashboard Analítico
- Interface de Predição
